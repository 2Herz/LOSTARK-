로아 귀속재료 계산기

내 원정대 내 각 캐릭터 별 귀속재료 값어치와 원정대 총합값어치를 계산할 수 있는 계산기!

보유수량만 입력하고 시세갱신 체크박스 체크해두면 자동계산!

그래프로 보유자산(?) 의 변동폭도 알 수 있어용~!

[사용법]

1. 로스트아크 공식 홈페이지에서 API키를 발급받는다
2. 프로그램을 시작한다
3. 발급받은 API키를 입력하면 프로그램이 시작됨
4. 좌측상단에 캐릭터 닉네임을 입력한다.
5. 원정대 동기화 버튼을 누른다
6. 보유수량의 본인의 재료수량을 입력한다
7. 갱신버튼 or 시세갱신을 체크한다
