# 🪙 로아 귀속재료 계산기

> 내 원정대의 **캐릭터별 귀속재료 값어치**와 **원정대 총 자산**을 한눈에!

보유수량만 입력해두면 거래소 시세를 가져와서 자동으로 계산해줘요.
그래프로 원정대 자산이 날마다 어떻게 변하는지도 볼 수 있어용~!

---

## ✨ 주요 기능

- **원정대 자동 불러오기** : 닉네임 하나만 입력하면 원정대 캐릭터를 아이템 레벨 순으로 불러와요
- **실시간 시세 계산** : 로스트아크 공식 API로 거래소 시세를 가져와서 재료 값어치를 계산해요
- **상위 / 하위 재료 구분** : 결정·위대한·상급 재료와 일반 재료를 따로 계산해요
- **시세 등락 표시** : 직전 갱신보다 오르면 🔺빨강, 내리면 🔻파랑으로 보여줘요
- **자산 그래프** : 하루 한 번 원정대 총 자산을 기록해서 변동 추이를 그래프로 보여줘요
- **백그라운드 자동 갱신** : 최소화하면 트레이로 들어가서 5분마다 시세를 갱신해요
- **자동 백업** : 저장 파일이 손상되면 백업에서 자동으로 복구해요

## 📦 계산하는 재료

| 구분 | 상위 재료 | 하위 재료 |
|---|---|---|
| 파괴석 | 운명의 파괴석 결정 | 운명의 파괴석 |
| 수호석 | 운명의 수호석 결정 | 운명의 수호석 |
| 돌파석 | 위대한 운명의 돌파석 | 운명의 돌파석 |
| 융화 재료 | 상급 아비도스 융화 재료 | 아비도스 융화 재료 |
| 운명의 파편 | 운명의 파편 (공통) | |
| 숨결 | 용암의 숨결 / 빙하의 숨결 (공통) | |

## 🚀 사용법

### 1. API 키 발급 (최초 1회)
1. [로스트아크 개발자 센터](https://developer-lostark.game.onstove.com/)에 로그인해요
2. **GET ACCESS TO LOSTARK API** 메뉴에서 클라이언트를 만들고 API 키를 발급받아요

### 2. 처음 실행
1. `LOSTARK 귀속재료 값어치 계산기.exe`를 실행해요
2. API 키 입력 창이 뜨면 발급받은 키를 붙여넣고 **[저장 및 시작]**을 눌러요

### 3. 원정대 불러오기
1. 좌측 상단 입력칸에 **아무 캐릭터 닉네임**이나 입력해요
2. **[원정대 동기화]**를 누르면 원정대 캐릭터가 목록에 추가돼요

### 4. 보유수량 입력
1. 목록에서 캐릭터를 골라요
2. 표의 **보유수량(상위) / 보유수량(하위)** 줄에 그 캐릭터가 가진 재료 수량을 입력해요
3. 입력하면 바로 저장되고, 캐릭터마다 따로 기록돼요

### 5. 시세 갱신
- **[갱신]** 버튼 : 지금 바로 시세를 가져와서 계산해요
- **[시세갱신]** 체크박스 : 켜두면 5분마다 자동으로 갱신해요

> 💡 창을 최소화하면 트레이로 들어가서 백그라운드에서 계속 갱신해요.
> 트레이 아이콘을 더블클릭하면 다시 열 수 있어요.

## 🔄 업데이트 방법

> ⚠️ **꼭 확인해 주세요!**
> 원정대와 보유수량, 자산 기록은 **exe와 같은 폴더**의 `LostArkRosterData.json`에 저장돼요.
> 새 버전을 다른 폴더에 풀었다면 이 파일을 **새 폴더로 복사**해 주세요.
> 복사하지 않으면 데이터가 비어 보여요.

- 새 버전이 나오면 프로그램을 실행할 때 업데이트 안내가 떠요
- 다른 폴더에서 실행하면 API 키를 다시 입력해야 할 수 있어요

---

## ❓ 문제 해결

| 증상 | 해결 방법 |
|---|---|
| "API 키가 유효하지 않습니다" | 트레이 아이콘 우클릭 → **[API 키 변경]**으로 키를 다시 입력해 주세요 |
| "API 호출 한도를 초과했습니다" | 잠시 후 다시 시도해 주세요. 갱신 1회에 API를 11번 호출해요 |
| "캐릭터 정보를 찾을 수 없습니다" | 닉네임 오타를 확인해 주세요 |
| 데이터가 사라졌어요 | `LostArkRosterData.json`이 exe와 같은 폴더에 있는지 확인해 주세요 |
| "저장 파일이 손상되어…" 안내가 떠요 | 백업에서 자동 복구된 거예요. 손상된 원본은 `.corrupt_날짜` 파일로 남아 있어요 |
| 서버 상태 확인 실패 | 인터넷 연결을 확인해 주세요. [예]를 누르면 그대로 실행할 수 있어요 |

## 📁 생성되는 파일

| 파일 | 설명 |
|---|---|
| `LostArkRosterData.json` | 원정대, 보유수량, 자산 기록 |
| `LostArkRosterData.json.bak` | 직전 저장본 (자동 백업, 지우지 마세요) |
| `LostArkRosterData.json.corrupt_*` | 손상되어 보관된 파일 (복구가 끝났으면 지워도 돼요) |

API 키는 이 폴더가 아니라 **Windows 사용자 설정**에 저장돼요. 다른 곳으로 전송되지 않아요.
